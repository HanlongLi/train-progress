# train-progress

Plugin marketplace for Claude Code and Codex. Add this repository as a marketplace and install from it:

```
/plugin install train-progress --marketplace hanlongli/train-progress      # Claude Code
codex plugin marketplace add hanlongli/train-progress && codex plugin add train-progress@local-mods   # Codex
```

- [train-progress](train-progress/): live progress bars for training runs and other long tasks, in Claude Code, Codex, OpenCode and any terminal.
